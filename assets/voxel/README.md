# Original Voxel Starter Assets

These assets were generated specifically for this portfolio project. They do
not contain third-party meshes, textures, logos, or trademarks.

## Files

- `pine-tree.glb`: reusable forest prop
- `round-rock.glb`: reusable terrain prop
- `soft-cloud.glb`: reusable atmospheric prop
- `forest-observatory.glb`: first portfolio landmark

All models use a shared chunky voxel scale, flat geometry, and a small
material palette so they can be instanced and recolored in Three.js.
